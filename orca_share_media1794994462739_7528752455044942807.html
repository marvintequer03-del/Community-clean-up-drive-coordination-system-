About the System

Community Clean-Up Drive Coordination System

This web-based system helps administrators, volunteers, and barangay officials organize community clean-up activities.


Purpose: To make event creation, volunteer registration, scheduling, proof submission, and report generation easier.


Process: Login → Dashboard → View/Create Event → Volunteer Registration → Schedule → Clean-Up Drive → Upload Proof → Generate Report.
